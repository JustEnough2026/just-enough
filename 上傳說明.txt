【食材有限 v5 清楚版｜上傳方式】

1. 先把這個 ZIP 解壓縮。
2. 打開 GitHub 的 just-enough 專案。
3. 把解壓縮後「所有檔案」拖進 GitHub 上傳頁面。
4. 如果出現同名檔案，全部選「覆蓋 / Replace」。
5. 原本 GitHub 裡其他餐點照片不要刪除。
6. Commit changes 後，等待約 1～3 分鐘再重新整理網站。

這版重點：
- 版面改成 1→2→3→4 點餐步驟，更清楚。
- 口味選項會顯示 ✓。

- LINE 社群密碼：0000。
- 所有 ＋／－、口味、餐具、查看訂單與 LINE 按鈕皆保留。
